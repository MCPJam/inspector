82:When `HTTPS_PROXY` or `HTTP_PROXY` is set (either case), the CLI process sends its `fetch` requests through the proxy and honors `NO_PROXY`: MCPJam's API, model providers and MCP servers over HTTP. `HTTPS_PROXY` covers `https` destinations and `HTTP_PROXY` covers `http` ones; with only `HTTP_PROXY` set, `https` requests use it too. `localhost`, `127.0.0.1` and `[::1]` always connect directly, so local MCP servers and the local Inspector keep working. A value without a scheme, such as `proxy.corp.com:8080`, means `http://`; a value that is not an http(s) URL is ignored with a warning.
