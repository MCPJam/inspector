New in v3

  • Own-server failure opens an editable form — name, transport, URL, auth, and a header row — instead of bouncing back to one field. The secondary path there is always Excalidraw.
  • Demo failure is its own screen. No "Try again", no "Edit URL" — the user typed nothing and can fix nothing. It says it's on us and pivots to connecting their own server.
  • Success moment before Playground: a check that draws itself and a tool count. One click through, no confetti.
  • Preloaded prompt in the composer with the send button glowing — nothing to type to reach first value.
  • Guest sign-up bar under the Playground, dismissible. Secondary goal, so it never blocks.
  • Home banner persists whenever the only connected server is the demo.

Still open

  • Excalidraw is a single point of failure for every new user without a server. A second demo — ideally one you control — removes that.
  • 403 is not 401. Authenticated-but-forbidden can't be fixed by re-running OAuth; offering it would loop them. Needs its own copy.
  • CORS deserves its own message. A server that works from a CLI can still refuse the browser origin, and generic "couldn't connect" sends people hunting the wrong thing.
