Usage: mcpjam cloud eval run [options]

Start an eval run of an existing suite, or upload a versioned suite file and run
it. The upload-and-launch has a 120s deadline overall, not per request (raise it
with the global --timeout <ms>); --wait-timeout bounds the RUN instead.

Options:
  --suite <id-or-name>                      Eval suite name or ID
  --file <path>                             Versioned suite file to upload and run (.yaml or .json, or - for stdin)
  --project <id-or-name>                    Project name or ID (defaults to the most recently updated project)
  --server <id-or-name...>                  Override the suite's saved server selection (HTTP servers only)
  --environment <id-or-name...>             Attached project environment(s) to run. Several values start one PAID RUN each.
  --client <id-or-name...>                  Attached client(s) to run, so the run is stamped with that client's config. Several values start one PAID RUN each.
  --host <id-or-name...>                    Deprecated alias for --client. NOT the host-compat catalog id `mcpjam tools --host` takes.
  --all-targets                             Run EVERY attached environment (or, if none, every attached host) — one PAID RUN per target
  --iterations <n>                          Run each case this many times under verdict policy 2 (1-10)
  --repetitions <n>                         Legacy spelling of --iterations
  --case <id-or-title...>                   Run only these cases instead of the whole suite
  --exclude-skills                          Run the 'without skills' arm: no skills are pinned, and the run is labelled as excluded
  --refresh-snapshot                        PERSISTS a new host-config snapshot on the suite, changing every future run of it. Single-target runs only.
  --notes <text>                            Free-text note stored on the run
  --min-pass-rate <n>                       Pass threshold for this run (0-100)
  --match-options <json>                    Tool-call match options for this run, e.g. '{"toolCallOrder":"exact"}'
  --idempotency-key <key>                   Retry key for a lost launch response; for --file, one is minted and printed when omitted
  --wait                                    Wait for every started run to reach a terminal status
  --wait-timeout <ms>                       Maximum time to wait for completion (default 600000; a run held for its judge gets up to 31 more minutes unless this flag is set)
  --reporter <json-summary|junit-xml|html>  Render the completed run report to stdout
  --out <path>                              Atomically write the completed report selected by --reporter (default: json-summary)
  --compose-client <id-or-name>             Compose a stack to run instead of naming a saved environment: the client it runs as. Default is EPHEMERAL (does not attach to the suite).
  --compose-host <id-or-name>               Deprecated alias for --compose-client
