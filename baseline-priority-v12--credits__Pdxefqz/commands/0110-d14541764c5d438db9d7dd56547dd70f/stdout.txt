- [Read the organization's spend budget](https://docs.mcpjam.com/api-reference/catalog/read-the-organizations-spend-budget.md): The ceiling on what this organization may spend on MCPJam-billed work — chat, evals, judges and computer time — in the current billing window, and how much of it has been spent.
- [List organizations](https://docs.mcpjam.com/api-reference/catalog/list-organizations.md): The organizations the caller belongs to — the source of the `organizationId` that `GET /projects` filters by and `POST /projects` accepts. An API key is bound to one organization and only ever sees that one. Read-only: organization, member, role and billing changes are not part of the public API.
- [Request insights for an eval run](https://docs.mcpjam.com/api-reference/evals/request-insights-for-an-eval-run.md): **No credits are consumed** — the model cost is on MCPJam. Runs a model over the finished run and draws on the same shared `insightsPerDay` request ledger as swarm and user-testing insights.
- [Usage breakdown](https://docs.mcpjam.com/api-reference/studies/usage-breakdown.md): Which models, tools and servers the study's sessions used.
- [Request insights for the current window](https://docs.mcpjam.com/api-reference/studies/request-insights-for-the-current-window.md): **No credits are consumed** — the model cost is on MCPJam. Runs a model over the study's current window and draws on the organization's `insightsPerDay` ledger, which counts REQUESTS and is SHARED with eval-run and swarm run insights, so a request here takes one from there.
