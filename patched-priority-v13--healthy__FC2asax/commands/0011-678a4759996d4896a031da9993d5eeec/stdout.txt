Usage: mcpjam cloud projects [options] [command]

Operate the MCP servers saved in your hosted MCPJam projects

Options:
  -h, --help              display help for command

Commands:
  list [options]          List the projects you can access
  create [options]        Create a hosted MCPJam project
  update [options]        Update project metadata
  delete [options]        Delete a project and its project-owned resources
  capabilities [options]  Show what you may do in a project: your role, which
                          betas the organization has, your plan's limits, and a
                          can-block of booleans. Ask this before scripting
                          anything that authors, launches or publishes.
  servers [options]       List and manage the servers saved in a project
  status [options]        Health-check every server in a project (hosted doctor
                          per server)
  help [command]          display help for command
