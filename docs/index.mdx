MCPJam lets you test and evaluate your **MCP server, MCP app or ChatGPT app** before you ship it. Test tools, prompts, resources and OAuth across 18 client configurations and 170+ LLMs, with every JSON-RPC message visible. Then run evals to track accuracy over time and catch regressions before they reach production. It's open source.

## Start testing

There are four ways to use MCPJam: your **coding agent** runs MCPJam's tools for you; the **Inspector** is an app for testing servers by hand; the **CLI** runs checks in your shell and CI; the **SDK** runs them in your test suite.

<Tabs>
  <Tab title="In your agent">
    <AgentConnect />

    To install the MCPJam skill or the account MCP server instead, see [Installation](/installation#add-mcpjam-to-your-coding-agent).
  </Tab>
  <Tab title="In Inspector">
    <Steps>
      <Step title="Open Inspector">
        Run this in your terminal (needs Node.js) and open the `localhost` link it prints:

        ```bash
        npx @mcpjam/inspector@latest
        ```
      </Step>
      <Step title="Connect a server">
        MCPJam asks you to connect to your MCP server. Paste your server's URL, ending in `/mcp`, or a command such as `npx -y @modelcontextprotocol/server-everything`, and click **Connect**.

        <Check>
          The dialog reads "Connected to" followed by your server's name.
        </Check>
      </Step>
      <Step title="Send your first prompt">
        Click **Open Playground**. MCPJam fills in the prompt `What can this server do?`; send it to watch the model call your tools. You don't need an API key or a ChatGPT or Claude subscription.

        Open the debug icons on any result to see tool input and output, widget state, CSP activity and the JSON-RPC messages. See [Playground](/inspector/playground).
      </Step>
    </Steps>
  </Tab>
  <Tab title="CLI">
    Run connectivity, OAuth, conformance and tool checks from your shell or CI, with JUnit or JSON output. It tests local servers over STDIO (`--command`) and HTTP (`--url`).

    ```bash
    npm i -g @mcpjam/cli
    ```

    See [CLI overview](/cli/overview).
  </Tab>
  <Tab title="SDK">
    Write unit tests, end-to-end tests and evals in TypeScript with Jest or Vitest. It spawns local STDIO servers or connects over HTTP.

    ```bash
    npm install @mcpjam/sdk
    ```

    See [SDK](/sdk).
  </Tab>
</Tabs>

## How to test MCP

Find what you want to test, then follow the guide for the tool you use. The MCP column lists the tools [MCPJam's MCP server](/cli/mcp-server) gives your coding agent for that check.

| What to test | Inspector | CLI | MCP |
| --- | --- | --- | --- |
| **Connection and capabilities**<br />The server starts, completes the handshake and declares what it supports | [Connect servers](/inspector/connecting-servers) | [`server probe`, `server doctor`](/cli/server-inspection) | [connect_server, server_info, server_doctor](/cli/mcp-server#tools) |
| **Tools**<br />Tools list, accept valid arguments and return usable results | [Tools](/inspector/tools-prompts-resources#tools) | [Tools](/cli/tools-resources-prompts#tools) | [list_tools, call_tool](/cli/mcp-server#exercising-the-target) |
| **Resources and templates**<br />Resources list and read; templates resolve | [MCP Inspector](/inspector/tools-prompts-resources) | [Resources](/cli/tools-resources-prompts#resources) | [list_resources, read_resource](/cli/mcp-server#exercising-the-target) |
| **Prompts**<br />Prompts list and render with their arguments | [MCP Inspector](/inspector/tools-prompts-resources) | [Prompts](/cli/tools-resources-prompts#prompts) | [list_prompts, get_prompt](/cli/mcp-server#exercising-the-target) |
| **Elicitation and multi-round input**<br />The server asks the user for input mid-call and resumes with the answer | [Elicitation requests](/inspector/tools-prompts-resources#elicitation-requests) | [Tools, Resources & Prompts](/cli/tools-resources-prompts) | — |
| **Notifications and logs**<br />`list_changed`, log messages and resource updates arrive in a live session | [Tracing & debugging](/inspector/debugging) | [MCPJam as an MCP server](/cli/mcp-server) | [get_notifications](/cli/mcp-server#exercising-the-target) |
| **MCP Events**<br />The server declares events and delivers them by push, poll or webhook | — | [MCP Events](/cli/events) | — |
| **MCP Tasks**<br />Long-running calls create, report and finish tasks | [Tasks tab](/inspector/mcp-support#extensions) | [MCP Tasks](/cli/tasks), [Tasks conformance](/cli/tasks-conformance) | — |
| **Skills over MCP**<br />The server serves skills a client can list and load | [Skills over MCP](/inspector/skills#skills-over-mcp-server-provided-skills) | [Skills from the CLI](/inspector/skills#inspecting-a-server%E2%80%99s-skills-from-the-cli) | [list_skills, get_skill](/cli/mcp-server#skills-over-mcp) |
| **OAuth**<br />Each step of the authorization flow, across protocol versions | [OAuth Debugger](/inspector/guided-oauth) | [OAuth conformance](/cli/oauth-conformance), [OAuth login](/cli/oauth-login) | [probe_server](/cli/mcp-server#stateless-diagnostics) (auth discovery) |
| **Enterprise sign-in (XAA)**<br />Cross-app access token exchange | [XAA Debugger](/inspector/xaa-debugger) | [XAA Debugger (CLI)](/cli/xaa) | — |
| **MCP Apps and ChatGPT Apps**<br />Widgets render and talk to the host | [First MCP App](/guides/first-mcp-app) | [MCP Apps conformance](/cli/apps-conformance) | — |
| **Client compatibility**<br />Your server works in each client's configuration | [Host compatibility](/inspector/host-compat) | [`compat`](/cli/reference#compat-command) | — |
| **Protocol versions**<br />Behavior on each MCP protocol version | [MCP protocol versions](/inspector/protocol-versions) | [Server inspection](/cli/server-inspection) | [server_info](/cli/mcp-server#tools) (negotiated version) |

## Good to know

- **You don't have a server yet.** When MCPJam asks you to connect, click **Try the Excalidraw demo server**.
- **Your server has a public HTTPS URL.** Skip the install and open the web app at [app.mcpjam.com](https://app.mcpjam.com). It can't reach `localhost` or STDIO servers.
- **You'd rather not use Node.js.** Download the desktop app for [Mac](https://github.com/MCPJam/inspector/releases/latest/download/MCPJam.Inspector.dmg) or [Windows](https://github.com/MCPJam/inspector/releases/latest/download/MCPJam-Inspector-Setup.exe), or run the Inspector in [Docker](/installation#docker). See [Installation](/installation#which-one-do-i-need) to compare them.
- **Your server needs sign-in.** Add a bearer token, or use the [OAuth Debugger](/inspector/guided-oauth).
- **Adding another server.** Open **Connect** in the sidebar, choose **Servers**, and click **Add Server**. When you're signed out, the sidebar item is **Servers**.
