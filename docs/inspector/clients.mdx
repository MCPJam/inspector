A **client** is a saved configuration that makes MCPJam behave like one MCP host, such as ChatGPT Desktop, Claude Desktop or Cursor. It sets the model, what MCPJam advertises when it connects to your server, and how MCP Apps are rendered and sandboxed. The Playground, Evaluate, Swarms and User Testing all run through a client, so the same settings apply wherever you test.

Use a client when you want to check how your server behaves in a particular host before you ship to it. MCPJam emulates that host; it isn't the official app.

## Before you start

- **A project where you're an Admin**, since only Admins can create clients. See [Sharing Projects](/inspector/projects#sharing-projects).
- **A project with at least one server.** Follow [Start testing](/#start-testing) to connect the Excalidraw demo server if you don't have one.

<Steps titleSize="h3">
  <Step title="Open the client view" id="open-the-client-view">
    In the sidebar, select **Connect**, then select **Client** at the top of the page.

    The view shows the active client: a diagram of its settings on the left and its details on the right. The switcher next to **Add client** shows its name and position, for example `3 / 5`.
  </Step>
  <Step title="Create a client from a template" id="create-a-client">
    Select **Add client**. In the **New Client** dialog, under **Start from template**, select **ChatGPT Desktop**. The **Name** field fills in with the template's name. Select **Create**.

    <Frame>
      <img src="/images/clients/v1/new-client-dialog.png" alt="The New Client dialog with Start from template listing hosts such as ChatGPT Desktop, Claude Desktop and Cursor, a Name field, and Cancel and Create buttons" width="360" />
    </Frame>

    <Check>A message says **Client "ChatGPT Desktop" created**, and the switcher now shows **ChatGPT Desktop**.</Check>
  </Step>
  <Step title="Check what the template set" id="check-the-settings">
    The panel on the right has four tabs: **Agent**, **MCP Protocol**, **Apps** and **Tools**.

    - **Agent** shows the model the client runs and how it handles tools.
    - **MCP Protocol** shows what MCPJam advertises when it connects to your server.
    - **Apps** shows how MCP App views are rendered and sandboxed.
    - **Tools** shows the built-in tools the client offers besides your MCP servers, such as web search.

    <Frame>
      <img src="/images/clients/v1/client-panel.png" alt="The ChatGPT Desktop client panel with the Agent, MCP Protocol, Apps and Tools tabs, and the Agent tab showing the model, reasoning effort, temperature and tool settings" width="420" />
    </Frame>

    You don't need to change anything now. Each setting is described in the [Clients reference](/inspector/clients/reference).
  </Step>
  <Step title="Use the client in the Playground" id="use-the-client">
    Open **Playground**. On any pane, select the settings icon and set **Client** to **ChatGPT Desktop**.

    <Check>That pane now runs your prompts with the client's model and settings.</Check>
  </Step>
</Steps>

## What you did

You created a client from a template, looked at the settings it brought, and used it in the Playground.
