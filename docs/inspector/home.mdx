Home is where MCPJam lands you once you're signed in with an active organization. It answers two questions at a glance: what has my org been doing, and what can I connect right now without setting anything up.

<Note>
The Home dashboard is available in the hosted app at [app.mcpjam.com](https://app.mcpjam.com) and requires you to be signed in with an active organization.
</Note>

## What Home gives you

| Section | What it's for |
|---|---|
| **Greeting** | A time-aware greeting with your first name |
| **Org stats strip** | Live counts for teammates, projects, servers, eval suites, tool executions, and messages |
| **MCPJam Agent composer** | Start or resume an agent conversation without leaving the page |
| **What's new** | Recent platform releases, with per-item dismiss and **Clear all** |
| **Recommended servers** and **Recommended clients** | Side-by-side grid for connecting a server or spinning up a sandbox client |

## Your first visit

<Steps>
<Step title="Open the Home tab">
The Home tab loads at `/home` (also the root `/`). If you don't have an active organization yet, the page shows a **Get started** prompt that takes you to the Organizations page.

<Note>
If you are signing in for the first time, MCPJam routes you to the [Playground](/inspector/playground) instead of Home so you can start exploring right away. After your first visit to the Playground, subsequent logins land on Home as normal.
</Note>

<Check>
You see the greeting with your first name and the stats strip below it.
</Check>
</Step>

<Step title="Connect a recommended server">
Make sure you have an active project selected, then click **Connect** next to a server in **Recommended servers**. MCPJam creates the server on your active project and navigates to the Connect tab.

If the server is already connected to your project, you'll see an info toast and be taken to the Connect tab instead.

<Check>
The server appears in the Connect tab under your active project.
</Check>
</Step>

<Step title="Create a sandbox client">
**Recommended clients** creates a pre-configured sandbox client from a template. Available templates include Claude, ChatGPT, and Cursor.

With an active project selected, click the template you want. MCPJam creates the client on your active project and opens it in the Clients tab.

<Check>
Your client opens in the Clients tab, already pointed at your project. You now have a server and a client, which is everything the [Playground](/inspector/playground) needs.
</Check>
</Step>
</Steps>

## Org stats strip

The stats strip appears directly below the greeting and shows six metrics for your organization:

| Stat | Description |
|------|-------------|
| Teammates | Number of members in your organization |
| Projects | Total projects in your organization |
| Servers | Total MCP servers across all projects |
| Eval suites | Number of evaluation suites |
| Tool executions · 30d | Tool calls made in the last 30 days |
| Messages · 30d | Messages sent in the last 30 days |

Click **projects** or **servers** to jump to the Connect tab. Click **eval suites** to jump to the Evals tab. The 30-day metrics refresh automatically in the background.

## What's new

The **What's new** section appears above the recommended servers and clients grid and lists recent platform updates.

- **Hover** a row to open a popover with a muted looping video preview (or a YouTube thumbnail if no preview clip is available).
- **Click** a row to open a panel with the full video, a "Watch on YouTube" link, an optional Docs link, and the full release description. Click **Got it** or press **Escape** to close.
- **Dismiss** a single update with the **✕** button that appears on hover.
- **Clear all** dismisses every pending update at once.
- If there are more than three updates, a **View more** button expands the list inline.

## MCPJam Agent panel

The MCPJam Agent is a persistent chat panel that lets you ask questions about docs, evals, and tools without leaving your current tab. It is available on every tab — Playground, Evals, Clients, and others — so you can keep a conversation going while you work.

Open it in one of two ways:

- Click the **Ask MCPJam** button in the top-right header bar.
- Press **⌘\\** (Mac) or **Ctrl+\\** (Windows / Linux) from anywhere in the app. The shortcut is ignored when focus is inside a text input, textarea, or content-editable field.

The agent acts by driving the inspector UI directly — every action it takes is visible on your screen as it happens. It uses the documentation and web search to answer knowledge questions, and navigates or operates the app on your behalf through UI actions.

| Capability | What it does |
|------------|-------------|
| **Navigate** | Opens tabs, pages, and panels in the inspector |
| **Playground** | Opens the playground, selects tools, and prefills or runs tool calls |
| **Server management** | Adds, connects, disconnects, and removes MCP servers on the Connect screen by chat |
| **App snapshot** | Reads the current state of the UI to observe before acting |
| **Documentation & web search** | Answers questions about MCPJam features and MCP concepts |
| **Clarifying questions** | Asks a multiple-choice question inline when a request is genuinely ambiguous, then continues the same turn with your answer |

<AccordionGroup>
<Accordion title="How server management and clarifying questions behave">
For server management, adding and connecting are always two separate steps — the agent saves the server first, then connects it, so you can see each change as it happens. If a server requires OAuth authorization, the agent reports that and waits for you to click **Authorize** yourself; it never redirects the page on your behalf. Removing a server is irreversible from chat, so it always pauses for approval even when the **Tool approval** toggle is off.

When the agent needs to clarify your intent before acting, it renders a question card inline in the thread with 2–4 choices. A **Something else** option is always present so you can answer in your own words if none of the choices fit. Once you pick an option or type a free-text answer, the agent continues the same turn with your response. If you send a new message or press **Stop** instead of answering, the question is dismissed and the agent does not attempt to answer the original request — it responds to whatever you say next.

Actions that mutate the UI (such as running a tool call) pause for your explicit approval before they run when the **Tool approval** toggle is on. Destructive actions — those that can't be undone by looking at the screen — always pause for approval regardless of the toggle setting.
</Accordion>

<Accordion title="Tool approval">
The composer footer includes a **Tool approval** toggle (shield icon).

- **Toggle off (default)** — Additive UI actions apply immediately. Destructive actions (those that can't be undone by looking at the screen) still pause for approval.
- **Toggle on (strict)** — Every mutating UI action pauses before it runs.

When the agent pauses, an **Approve / Deny** pill appears in the chat. Denying a call is final — the agent will not retry it automatically. The preference is saved to your browser's local storage and shared across the Home takeover and the side panel.
</Accordion>

<Accordion title="Using and resizing the panel">
- **New chat** — Click **New chat** in the panel header to start a fresh conversation.
- **Resume a session** — Previously started sessions are listed in the panel's home view. Click one to continue.
- **Resize** — Drag the left edge of the panel to adjust its width. The minimum width is 360 px; the maximum is 50% of the viewport. Dragging below the minimum snaps the panel closed.
- **Close** — Click the **✕** button in the panel header, or press the keyboard shortcut again.

On mobile viewports (below 768 px) the panel opens as a full-width drawer instead of an inline side panel.
</Accordion>

<Accordion title="Widget rendering and persistence">
The agent supports MCP Apps widget rendering. When a workspace tool returns an interactive widget — for example, asking "show my servers" — the widget renders inline in the chat, just like widgets in the LLM Playground. You can interact with the widget directly without leaving the panel.

The panel's open state, width, and active session are saved to your browser's local storage and restored on reload. Conversations persist server-side, so you can close and reopen the panel without losing your chat history.
</Accordion>
</AccordionGroup>

<Note>
The MCPJam Agent panel is available to all signed-in users.
</Note>

## Notifications

Notifications are accessible from the sidebar. Click **Notifications** next to the **Support** entry at the bottom of the sidebar to open the notifications panel. Unread notifications show a badge count that is visible in both expanded and collapsed sidebar states.
