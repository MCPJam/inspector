Home is where MCPJam opens. It shows what your organization has been doing, lets you connect a recommended server or create a client in one click, and gives you a chat box for the MCPJam agent.

The page shows, from top to bottom:

- A greeting with your first name.
- A stats strip with counts for your organization.
- A composer that starts or resumes an MCPJam agent conversation.
- **What's new**, a short list of recent MCPJam releases.
- **Recommended servers** and **Recommended clients**, side by side.

## Org stats strip

The stats strip sits below the greeting and shows six metrics for your organization:

| Stat | Description |
|------|-------------|
| Teammates | Number of members in your organization |
| Projects | Total projects in your organization |
| Servers | Total MCP servers across all projects |
| Eval suites | Number of evaluation suites |
| Tool executions · 30d | Tool calls made in the last 30 days |
| Messages · 30d | Messages sent in the last 30 days |

Click **projects** or **servers** to open the Connect tab. Click **eval suites** to open **Evaluate**.

## Recommended servers

**Recommended servers** lists MCP servers you can try. To connect one:

1. Select a project.
2. Click **Connect** next to the server.

MCPJam adds the server to your project and takes you to it.

## Recommended clients

**Recommended clients** creates a preconfigured sandbox client from a template, such as Claude, ChatGPT or Cursor. To create one:

1. Select a project.
2. Click the template.

MCPJam adds the client to your project and opens it in the Clients tab.

## What's new

**What's new** sits above the recommended servers and clients and lists recent MCPJam updates.

- **Hover** a row to preview its video.
- **Click** a row to open the full video, a "Watch on YouTube" link, an optional docs link and the release notes. Click **Got it** or press **Escape** to close.
- **Dismiss** one update with the **✕** button that appears on hover, or click **Clear all** to dismiss them all.
- With more than three updates, click the button below the list to show the rest.

## MCPJam Agent panel

The MCPJam agent answers questions about MCPJam and MCP, and operates the app for you while you watch. Its panel stays open as you move between tabs, so the conversation follows you.

### Opening the panel

- Click **Ask MCPJam** in the top-right of the header.
- Press **⌘\\** (Mac) or **Ctrl+\\** (Windows / Linux). The shortcut does nothing while you're typing in a text field.

### What the agent can do

Every action the agent takes happens in the visible UI, so you see each change as it's made.

| Capability | What it does |
|------------|-------------|
| **Navigate** | Opens tabs, pages, and panels in the inspector |
| **Playground** | Opens the playground, selects tools, and prefills or runs tool calls |
| **Server management** | Adds, connects, disconnects, and removes MCP servers on the Connect screen by chat |
| **App snapshot** | Reads the current state of the UI to observe before acting |
| **Documentation & web search** | Answers questions about MCPJam features and MCP concepts |
| **Clarifying questions** | Asks a multiple-choice question inline when a request is genuinely ambiguous, then continues the same turn with your answer |

When it adds a server, the agent saves it first and connects it as a second step. If the server needs OAuth, the agent tells you and waits for you to click **Authorize** yourself.

When a request is ambiguous, the agent shows a question card with two to four choices, plus **Something else** so you can answer in your own words. Pick an option or type an answer and the agent carries on. If you send a new message or stop the response instead, the agent drops the original request and responds to what you do next.

### What it costs

Ask MCPJam is free once you're signed in. It doesn't spend your organization's credits or free daily allowance, and it doesn't need a paid plan. Playground chat, evals and swarms still spend your credits or your own provider key.

The agent runs on a model MCPJam chooses, not the one selected in the Playground.

It has two limits, and you can't pay to lift either:

- **Daily limit**: after many turns in one UTC day, or once MCPJam's daily budget for the feature is spent, the panel says *"Ask MCPJam has reached today's limit. It resets at 00:00 UTC."* Nothing is charged.
- **Temporarily unavailable**: if something breaks on MCPJam's side, the panel says *"Ask MCPJam is temporarily unavailable."* Try again shortly.

### Using the panel

- **New chat**: Click **New chat** in the panel header to start a fresh conversation.
- **Resume**: Click a previous conversation in the panel's home view to continue it.
- **Resize**: Drag the panel's left edge. It ranges from 360 px to half the window, and dragging below the minimum closes it.
- **Close**: Click **✕** in the panel header, or press the keyboard shortcut again.

### Tool approval

The **Tool approval** toggle (shield icon) in the composer footer decides which actions wait for you.

- **Off (default)**: Actions that add to the UI run immediately.
- **On**: Every action that changes the UI waits for you.

Destructive actions, such as removing a server, always wait, whatever the toggle says. When the agent waits, click **Approve** or **Deny** in the chat. A denied action is final; the agent won't retry it. Your choice is saved in your browser.

### Widget rendering

When a tool returns an MCP Apps widget, for example when you ask "show my servers", the widget renders in the chat and you can use it there.

### Persistence

Conversations are saved to your account, so closing the panel doesn't lose them. The panel's open state, width and active conversation are saved in your browser and restored on reload.

## Notifications

Click **Notifications** next to **Support** at the bottom of the sidebar to open the notifications panel. A badge shows how many are unread, whether the sidebar is expanded or collapsed.

## Good to know

- **Home needs an organization.** Home is part of the hosted app at [app.mcpjam.com](https://app.mcpjam.com). If you aren't in an organization yet, click **Get started** to join or create one.
- **First sign-in.** The first time you sign in, a welcome overlay walks you through connecting your first server.
- **Guests.** If you haven't signed in, Ask MCPJam draws on the same shared free allowance as the rest of the hosted app.
- **Small screens.** Below 768 px wide, the agent panel opens as a full-width drawer.
- **WebMCP agents.** Browser agents that support WebMCP (Chrome with WebMCP enabled) can use the same actions through `document.modelContext` without opening the panel.
