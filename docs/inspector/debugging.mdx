When your server misbehaves, MCPJam shows you every message it sent and received, in the Playground and in the Tools, Prompts and Resources tabs.

## JSON-RPC logging

Every tab that talks to a connected server has a live JSON-RPC log. Each entry shows the direction (client → server or server → client), the method, a timestamp and the full payload. Click an entry to expand it.

See [Playground → JSON-RPC Logger](/inspector/playground#json-rpc-logger) and [MCP Inspector](/inspector/tools-prompts-resources#json-rpc-logging) for how it surfaces in each tab.

## Widget debugging

If your server renders ChatGPT Apps or MCP Apps widgets, you can inspect a widget's state and environment from its tool call.

### Debugging in the chat

Click a tool call in the chat to open its debug panel. For widgets, it shows:

- **Data**: the tool's input arguments and result
- **Widget State**: the state the widget has saved, updated live as the widget calls `setWidgetState`
- The environment passed to the widget, including theme, display mode, locale and device capabilities

### Debugging in the Tools tab

When you run an OpenAI Apps or MCP Apps tool from the Tools tab, the results panel has a button next to the Component and Raw JSON views that shows the same widget state and environment.

<Tip>
  Widget state carries over to later turns in the conversation, so keep it
  under 4k tokens.
</Tip>
