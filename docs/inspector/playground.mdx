The Playground is where you talk to your MCP server and inspect the model's tool calls and the messages behind them. Each pane emulates a client, such as Claude, ChatGPT or Cursor: MCPJam runs the model and renders widgets with that client's MCP Apps support and sandbox rules. It is not the official app, so check important behavior in the real client too. In this tutorial you ask the Excalidraw demo server to draw a rectangle, then look at the tool calls behind the answer.

## Before you start

Connect the Excalidraw demo server by following [Start testing](/#start-testing). You can do it as a guest. To use your own server instead, connect it the same way; the steps below still apply, with your tool names and results.

Each prompt uses MCPJam credits, because MCPJam provides the models. If a guest runs out of credits, the Playground asks you to sign in.

<Steps titleSize="h3">
  <Step title="Open the Playground" id="open-the-playground">
    In the sidebar, select **Playground**.

    You see one pane per client, side by side. Signed out, the panes are **Claude**, **ChatGPT**, and **Cursor**; your project may start with other clients, and the steps work the same. Each pane names its model and its number of servers. On the left, the **Tools** tab lists the server's five tools.

    If the panes say **No servers**, the demo server isn't connected in this chat. In the left rail, select **Connect a server**, then select **Excalidraw (App)** in the list to connect it.
  </Step>
  <Step title="Send a prompt" id="send-a-prompt">
    In the chat box at the bottom, enter this prompt and press **Enter**:

    ```text
    Draw a rectangle with the text Hello inside it.
    ```

    Each pane's model answers the prompt on its own. In the example run, each model called `read_me` and `create_view`, and the widget drew a rectangle with **Hello** inside it. Some models also called tool-search tools first. If a pane answers only in text, see [Compare clients](/inspector/playground/compare-hosts#compare-the-arguments).

    <Frame>
      <img src="/images/playground/v1/three-panes.png" alt="The Playground with Claude, ChatGPT and Cursor panes, each showing the Hello rectangle drawn by the Excalidraw widget, and the server's five tools in the left rail" />
    </Frame>

    Your run will differ from the screenshot: models change the wording, colors, and order of tool calls from run to run.
  </Step>
  <Step title="Read the trace" id="read-the-trace">
    In the **Claude** pane, select **Trace**.

    The trace lists each step of the turn with its latency: your message, the model's turns (**Agent**), and each tool call, such as **Tool · read_me** and **Tool · create_view**. Below it, **Prompt 1** shows the total time and tokens in and out.

    <Frame>
      <img src="/images/playground/v1/trace.png" alt="The Trace view of the Claude pane: User message, Agent, Tool read_me, Agent, Tool create_view, each with its latency, and Prompt 1 with token counts" width="330" />
    </Frame>

    To go back to the conversation, select **Chat**.
  </Step>
  <Step title="See what the model received" id="see-what-the-model-received">
    In the same pane, select **Raw**.

    Raw shows the JSON sent to the model: the `system` prompt, the `tools` with their input schemas, and the `messages`. For example, `create_view` requires one input, `elements`, a JSON string of Excalidraw elements.

    <Frame>
      <img src="/images/playground/v1/raw.png" alt="The Raw view of the Claude pane showing the system prompt and the read_me tool with its inputSchema" width="330" />
    </Frame>

    Select **Chat** to return.
  </Step>
  <Step title="Run a tool yourself" id="run-a-tool-yourself">
    You can call a tool without a model. In the left rail, under **Tools**, select `read_me`, then select **Run**.

    <Frame>
      <img src="/images/playground/v1/tools-rail-read-me.png" alt="The Tools rail with read_me selected, showing its Description, Input Schema and Annotations, and the Run button" width="310" />
    </Frame>

    The result appears in the chat as **Invoked read_me**, followed by the Excalidraw element reference the tool returns. `read_me` takes no input. **Input Schema** shows what a tool expects.

    To run a tool that takes input, select it and open **Parameters**. There is one field per input. Required fields are marked **required**. Optional fields start with **skip** selected; clear **skip** to include one. Objects and arrays take JSON. Fill in the fields, then select **Run**.
  </Step>
  <Step title="Watch the JSON-RPC log" id="watch-the-json-rpc-log">
    The right rail shows the JSON-RPC log: every message between the Playground, your servers, and the widgets, newest first. Find the `tools/call` request for `read_me` and its result, then select an entry to see its payload.

    To narrow the log, open the source filter and choose **Server** for server messages only, or **Apps** for widget messages. Choose **All** to see everything again.
  </Step>
</Steps>
