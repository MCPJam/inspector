Connect the MCPJam docs server to your AI coding tool and ask it about MCPJam without leaving your editor. Answers come from the current docs.

## MCP Server URL

```
https://docs.mcpjam.com/mcp
```

## Supported Applications

It works with any MCP client, including:

- Claude Desktop
- Claude Code
- Cursor
- VS Code with MCP extensions
- Other MCP-compatible tools

## Getting Started

1. In your AI application, add a new MCP server.
2. Paste the URL: `https://docs.mcpjam.com/mcp`
3. Ask a question about MCPJam.

## What You Can Ask

For example:

- "How do I connect to an MCP server in Inspector?"
- "What are the available transport protocols?"
- "How do I set up OAuth testing?"
- "Show me how to run evals"
- "What LLM providers are supported?"

## Troubleshooting

If you're having trouble connecting:

1. Check that your AI application supports remote MCP servers.
2. Check the URL for typos.
3. Check your internet connection.
4. Follow your application's MCP setup docs.
