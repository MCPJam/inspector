Add your own MCP server to the Inspector. MCPJam connects over **STDIO** or **Streamable HTTP**, and a project can have several servers connected at once.

New to MCPJam? [Get started](/getting-started) connects a demo server and sends a first prompt.

## Before you start

- **The Inspector open.** See [Installation](/installation).
- **Your server's start command or URL.** The [web app](/hosted/overview) connects to HTTPS URLs only. A local STDIO server or a plain HTTP URL needs the desktop app, the terminal or Docker.

<Steps titleSize="h3">
  <Step title="Choose the transport" id="choose-the-transport">
    <span id="stdio-servers"></span><span id="http-servers"></span>

    - **STDIO** if MCPJam starts your server with a command, for example `node /path/to/your/server.js`. Use the desktop app or the terminal.
    - **HTTP** if your server is already running at a URL, typically ending in `/mcp`. Any option works for HTTPS; plain HTTP needs the desktop app, the terminal or Docker.
  </Step>
  <Step title="Open the Add MCP Server dialog" id="open-the-dialog">
    In the sidebar, select **Connect**, then **Servers**, and select **Add Server**.
  </Step>
  <Step title="Enter the connection details" id="enter-the-details">
    Enter a **Server Name**. Under **Connection Type**, pick **STDIO** and enter the command, or pick **HTTP** and paste the URL. In the web app, **Connection Type** offers HTTPS only.

    For a STDIO server, use absolute paths (for example `/Users/yourname/project/server.py`) to avoid path resolution issues.

    <Frame>
      <img className="block" src="/images/connection/streamable.png" alt="The HTTP connection form with a URL field" width="300" />
    </Frame>

    Does your server need more? Add [environment variables](#environment-variables) (STDIO only), [custom headers](#custom-headers) or [authentication](#authentication) in the same dialog.
  </Step>
  <Step title="Add the server" id="add-the-server">
    Select **Add Server**.

    <Check>The server appears in the **Servers** list, and its card shows **Connected**. If it shows **Failed**, check the command or URL, then reconnect from the card's ⋯ menu.</Check>
  </Step>
</Steps>

## What you did

You added your server to the project and confirmed it connects.

**Next:** [Chat and inspect tool calls](/inspector/playground) with your server's tools.

## Connection options

Use these only if your server needs them.

### Environment variables

For a STDIO server, select **Add variable** in the **Environment Variables** section to pass values such as API tokens.

<Frame>
  <img className="block" src="/images/connection/stdio.png" alt="The STDIO connection form with a command field and an Environment Variables section" width="300" />
</Frame>

### Custom headers

Expand **Connection overrides** and select **Add header** under **Headers** to add request headers (for example, proxy auth or tenant identifiers). Headers are sent on every request to the server.

### Authentication

MCPJam follows the MCP authorization spec, with Dynamic Client Registration (DCR), client pre-registration and Client ID Metadata Documents (CIMD). Under **Authentication**, choose:

1. **Auto** (the default): connects anonymously first, then uses OAuth if the server requires it.
2. **No Authentication**.
3. **Bearer Token**, if you already have an API token and don't need to register an OAuth client.
4. **OAuth**, to obtain a token through [MCP Authorization](https://modelcontextprotocol.io/specification/draft/basic/authorization). You can optionally set scopes or a custom client ID and secret. To step through the flow, see the [OAuth Debugger](/inspector/guided-oauth).
5. **Cross-App Access (XAA)**. See the [XAA debugger](/inspector/xaa-debugger).

### Request timeout

Expand **Connection overrides** and set **Timeout** (in milliseconds). The field shows the default this server inherits from the active client, `10000` ms unless the client sets another. Increase it for slow or cold-start servers.
