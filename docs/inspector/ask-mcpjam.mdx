**Ask MCPJam** is a chat panel that answers questions about MCPJam and MCP and can operate the Inspector for you: open pages, run tools in the Playground, and add or connect servers. Everything it does happens on your screen.

When the agent needs your approval, it shows **Approve** and **Deny** in the chat and waits. With **Tool approval** off (the default), actions such as opening a page or adding a server happen right away. Turn **Tool approval** on to have the agent ask first: opening a page, for example, shows **Approve** and **Deny**, and **Deny** keeps you on the same screen.

## Try it

1. Select **Ask MCPJam** in the top-right corner, or press **⌘\\** (Mac) or **Ctrl+\\** (Windows and Linux).
2. Select the suggestion **How do I run an eval?** to put it in the message box, or type your own question. Press Enter to send it.
3. The agent answers in the panel. The docs searches it ran appear above the answer.

To try an action, select **Show my servers and check their health**. The agent opens your servers and reports what it finds.

## Open and close the panel

- Click the **Ask MCPJam** button in the top-right header bar.
- Press **⌘\\** (Mac) or **Ctrl+\\** (Windows / Linux) from anywhere in the app. The shortcut is ignored when focus is inside a text input, textarea, or content-editable field.

## What it can do

The agent acts by driving the inspector UI directly: every action it takes is visible on your screen as it happens. It uses the documentation and web search to answer knowledge questions, and navigates or operates the app on your behalf through UI actions.

| Capability | What it does |
|------------|-------------|
| **Navigate** | Opens tabs, pages, and panels in the inspector |
| **Playground** | Opens the playground, selects tools, and prefills or runs tool calls |
| **Server management** | Adds, connects, disconnects, and removes MCP servers on the Connect screen by chat |
| **App snapshot** | Reads the current state of the UI to observe before acting |
| **Documentation & web search** | Answers questions about MCPJam features and MCP concepts |
| **Clarifying questions** | Asks a multiple-choice question inline when a request is genuinely ambiguous, then continues the same turn with your answer |

## What it costs

Ask MCPJam is on MCPJam. Its turns and its web searches do not consume your organization's credits or its free daily allowance, and you do not need credits or a paid plan to use it, signing in is enough. Playground chat, evals, and swarms are unchanged; they still spend your credits or your own provider key.

The agent runs on a fixed model chosen by MCPJam, so it does not follow the model you have selected in the Playground.

There are limits, and neither of them is something you can buy your way past:

- **Today's limit**: after a large number of turns in one UTC day, or when MCPJam's daily budget for the feature is used up, the panel says *"Ask MCPJam has reached today's limit. It resets at 00:00 UTC."* Nothing is charged, and the limit clears at 00:00 UTC.
- **Temporarily unavailable**: an infrastructure problem on our side shows *"Ask MCPJam is temporarily unavailable."* Try again shortly.

Guests (visitors who have not signed in) use the agent on the same shared free allowance the rest of the hosted app gives them.

The same inspector actions are also available to browser-native WebMCP agents via `document.modelContext`, so an external agent can navigate, connect servers, and run playground actions without opening the Ask MCPJam panel. Browser support (Chrome with WebMCP enabled) is a prerequisite; where the API is absent, Ask MCPJam is unaffected.

For server management, adding and connecting are always two separate steps: the agent saves the server first, then connects it, so you can see each change as it happens. If a server requires OAuth authorization, the agent reports that and waits for you to click **Authorize** yourself; it never redirects the page on your behalf. Removing a server can't be undone from chat.

When the agent needs to clarify your intent before acting, it renders a question card inline in the thread with 2–4 choices. A **Something else** option is always present so you can answer in your own words if none of the choices fit. Once you pick an option or type a free-text answer, the agent continues the same turn with your response. If you send a new message or press **Stop** instead of answering, the question is dismissed and the agent does not attempt to answer the original request. It responds to whatever you say next.


## Panel controls

- **New chat**: Click **New chat** in the panel header to start a fresh conversation.
- **Go back to your last chat**: select **Recent chat** on the panel's start screen.
- **Resize**: Drag the left edge of the panel to adjust its width. The minimum width is 360 px; the maximum is 50% of the viewport. Dragging below the minimum snaps the panel closed.
- **Close**: Click the **✕** button in the panel header, or press the keyboard shortcut again.

## Tool approval

The chat box has a **Tool approval** switch. It is off by default.

| Tool approval | What asks for approval |
|---|---|
| **Off** | Opening a page and adding a server happen right away, without asking. |
| **On** | Actions such as opening a page or removing a server ask first. |

When the agent waits, select **Approve** or **Deny** in the chat. After **Deny**, the agent tells you the action didn't happen and doesn't try it again unless you ask.

## Widget rendering

The agent supports MCP Apps widget rendering. When a workspace tool returns an interactive widget (for example, asking "show my servers"), the widget renders inline in the chat, just like widgets in the LLM Playground. You can interact with the widget directly without leaving the panel.

## Close and reopen the panel

When you reopen the panel in the same project, your conversation is still there. If you switch projects, the panel opens on a new chat; select **Recent chat** to go back to your latest conversation. Select **New chat** in the panel header to start over.

On screens narrower than 768 px the panel opens full width.
