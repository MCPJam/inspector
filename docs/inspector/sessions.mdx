The Sessions page collects every transcript in your project into a single feed so you can find, review, and compare conversations without switching between surfaces.

<Note>
  Sessions is currently available to projects where the feature has been enabled.
  If the page redirects you elsewhere, the feature hasn't been turned on for your project yet.
</Note>

## What's included

Each row in the feed represents one conversation, regardless of where it originated:

| Source | What it covers |
|--------|---------------|
| **Playground** | Direct chats you started from the Playground tab |
| **User Testing** | Sessions from published chatbox scenarios |
| **Eval** | Individual iterations from eval suite runs |
| **Swarm** | Agent sessions generated by swarm journey runs |

## Layout

The page uses a resizable list-and-detail split. The left panel lists sessions; the right panel shows the selected session's transcript.

- Drag the divider between the two panels to resize them.
- Click any row to open its transcript in the right panel.
- If the transcript viewer doesn't fully support a session type yet, the right panel shows the session's metadata instead.

## Filtering and searching

### Source pills

Click one or more source pills (**Playground**, **User Testing**, **Eval**, **Swarm**) above the list to narrow the feed to those sources. Selecting all pills is the same as selecting none — the full feed is shown.

### Status filter

Use the **status** dropdown to show only **Active** or **Archived** sessions. The default shows all statuses.

### Search

Type in the search box to find sessions by title. Results are ranked by relevance rather than recency while a search is active; a note below the toolbar confirms this. Clear the search box to return to the recency-ordered feed.

## Session rows

Each row shows:

- **Title** — the session's resolved title, or a preview of the first message if no title was set.
- **Source badge** — which surface the session came from (Playground, User Testing, Eval, Swarm).
- **Yours / Shared** — whether you own the session or it's shared with the project.
- **Parent label** — for eval iterations, the suite run name or **Quick Run** (for iterations with no suite run); for swarm sessions, the journey run name; for User Testing sessions, the scenario name.
- **Readiness badge** — shown when the session has a readiness state.
- **First message preview** — the opening line of the conversation.
- **Timestamp** — how long ago the session last had activity.
- **Message count and model** — the number of messages and the model used, when available.

## Loading more sessions

The feed loads 25 sessions at a time. When more are available, a **Load more** button appears in the toolbar. The session count in the toolbar shows a `+` suffix (e.g. `25+ sessions`) while additional pages exist.
