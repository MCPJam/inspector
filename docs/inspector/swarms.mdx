The **Swarms** surface (`/swarms`) is the agent-facing view of the same host-backed chatbox used by [Chatbox](/inspector/chatbox). Select a host from the Connect sidebar, then use the tabs below to configure agent personas and review synthetic sessions.

## Tabs

### Publish

Configure and preview the chatbox for the selected host — the same publish panel available on the [Chatbox](/inspector/chatbox) surface.

### Personas

Define agent personas that run against the chatbox. Personas are available on the Swarms surface only; the human [Chatbox](/inspector/chatbox) surface does not expose persona management.

### Sessions

Browse sessions generated by agent swarms. The Sessions tab on the Swarms surface includes two controls not present on the human Chatbox:

- **Generate with AI** — opens a dialog to generate synthetic sessions using an AI agent.
- **Hide synthetic** — toggle to filter synthetic (AI-generated) sessions out of the list.

**Copying a session link** — click the copy icon on a thread to get a shareable deep link. The link opens the Swarms surface (`/swarms`) so the recipient lands on the agent-facing view.
