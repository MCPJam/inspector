## 1. Open the Inspector

Pick the option that matches where your server runs. A server with a public HTTPS URL works in every option. A server on `localhost` or over STDIO needs **Terminal** or **Desktop**.

## 2. Connect the Excalidraw demo server

On first launch, select **Get started**. In the **Connect to your MCP server** dialog, select **Try the Excalidraw demo server**. It is a hosted diagramming MCP app that needs no setup.

Don't see **Get started**? It only shows on a first visit. In the sidebar, select **Connect**, then **Servers**, then **Add Server**, and follow [Connect a server](/inspector/connecting-servers).

  <img src="/images/getting-started/connect-dialog.png" alt="The Connect to your MCP server dialog with the Server URL field, the Connect button, and Try the Excalidraw demo server" />
</Frame>

<Check>
You should see **Connected to Excalidraw (App)** and **5 tools ready to use**.
</Check>

<Frame>
  <img src="/images/getting-started/connected.png" alt="Connected to Excalidraw (App), 5 tools ready to use, and the Open Playground button" />
</Frame>

<Accordion title="Using your own server instead">
  Paste your server's URL in **Server URL** and select **Connect**. The web app accepts HTTPS URLs only.

  You should see **Connected to** followed by your server's name, and the number of tools it exposes. The rest of this page works the same way, with your server's tools in place of Excalidraw's.
</Accordion>

## 3. Send your first prompt

Select **Open Playground**. The chat is already filled in with this prompt:

```
What can this server do?
```

Send it. No API key, ngrok, or ChatGPT/Claude subscription needed.

<Frame>
  <img src="/images/getting-started/playground.png" alt="The Playground with Claude, ChatGPT and Cursor each answering the prompt in its own column, and the server's tools listed on the left" />
</Frame>

<Check>
You should see Claude, ChatGPT and Cursor each answer in their own column, and the server's tools listed on the left.
</Check>
