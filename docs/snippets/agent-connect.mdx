Connect MCPJam's MCP server to test your servers from your agent. Cursor and VS Code install it in one click; the other chips copy a ready-made command. Coding agents use the local server and need no account. ChatGPT and Claude connect to your MCPJam account at `https://mcp.mcpjam.com/mcp`.

Or paste this prompt into any of them. It walks the agent through the right setup for that client, then tests your server:

```text Prompt
Onboard onto MCPJam, use it to test the MCP server in this repo on a branch, and tell me how it did: https://www.mcpjam.com/prompt.md
```
