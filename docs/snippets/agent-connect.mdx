Connect MCPJam's MCP server to your coding agent so it can test your servers for you. It runs locally and needs no account. Click your agent: Claude Code and Codex copy a ready-made command, and Cursor and VS Code open an install prompt. Each one also shows the manual steps. The ChatGPT & Codex chip opens the MCPJam plugin, which connects to your MCPJam account instead, on the web or in the desktop app.

<ConnectClients />

Or paste this prompt into any of them. It walks the agent through the right setup for that client, then tests your server:

```text Prompt
Onboard onto MCPJam, use it to test the MCP server in this repo on a branch, and tell me how it did: https://www.mcpjam.com/prompt.md
```
