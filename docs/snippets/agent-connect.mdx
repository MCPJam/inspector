Connect MCPJam's MCP server to test your servers from your agent. The Claude Code and Codex chips copy a ready-made command; Cursor and VS Code open an install prompt in the app. Each chip also shows the manual steps, in case the link or copy doesn't work. Coding agents use the local server and need no account. The MCPJam plugin for ChatGPT and Codex connects to your MCPJam account; open it on the web or in the desktop app.

<ConnectClients />

Or paste this prompt into any of them. It walks the agent through the right setup for that client, then tests your server:

```text Prompt
Onboard onto MCPJam, use it to test the MCP server in this repo on a branch, and tell me how it did: https://www.mcpjam.com/prompt.md
```
