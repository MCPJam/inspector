The Inspector runs in four places. Pick one by where your MCP server runs.

| Option | Install, servers it reaches, and more |
| --- | --- |
| [Web app](#web-app) | **Install:** none. **Reaches:** HTTPS only. Share server URLs with your team. No Skills. Always the latest version. |
| [Desktop](#desktop-app) | **Install:** Mac or Windows download. **Reaches:** HTTPS, HTTP and local STDIO. Skills. Download again to update. |
| [Terminal](#terminal) | **Install:** Node.js. **Reaches:** HTTPS, HTTP and local STDIO. Skills. Updates on each run (`@latest`). |
| [Docker](#docker) | **Install:** Docker. **Reaches:** HTTPS and HTTP; STDIO inside the container only. Skills. Pull again to update. |

**Your server runs on `localhost`?** The web app can't reach it. Use the desktop app or the terminal, or Docker with `host.docker.internal`.

## Web app

Open [app.mcpjam.com](https://app.mcpjam.com). Nothing to install. It connects to HTTPS servers only. See [Use the web app](/hosted/overview).

## Desktop app

Download and run the installer for [Mac](https://github.com/MCPJam/inspector/releases/latest/download/MCPJam.Inspector.dmg) or [Windows](https://github.com/MCPJam/inspector/releases/latest/download/MCPJam-Inspector-Setup.exe). It doesn't need Node.js.

## Terminal

<CodeGroup>
```bash npm
npx @mcpjam/inspector@latest
```

```bash pnpm
pnpm dlx @mcpjam/inspector@latest
```

```bash yarn
yarn dlx @mcpjam/inspector@latest
```

```bash bun
bunx @mcpjam/inspector@latest
```
</CodeGroup>

<Check>The terminal prints a `localhost` link. Open it to see the Inspector.</Check>

On first start, the Inspector downloads the Chromium browser it uses to render widgets, with progress in the terminal. If the download fails, it retries after 30 seconds, 2 minutes and 10 minutes; select **Retry now** to try again sooner.

**In VS Code, Cursor or Windsurf**, run the same command in the editor's terminal. There's no extension. To start the Inspector with your project's `dev` script, see [Launch from code](/inspector/launch-from-code).

## Docker

```bash
docker pull mcpjam/mcp-inspector
docker run -p 127.0.0.1:6274:6274 mcpjam/mcp-inspector
```

<Check>The container logs print a private link. Open it to sign in to the Inspector.</Check>

- On macOS and Windows, open `http://127.0.0.1:6274`, not `localhost`.
- To reach a server on your machine, use `http://host.docker.internal:PORT` instead of `127.0.0.1`. On Linux, also pass `--add-host=host.docker.internal:host-gateway`.
- STDIO servers run inside the container. The image has Node.js and `npx`, but not Python or `uv`, and can't see your files.
