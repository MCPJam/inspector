A Claude Code or Codex turn no longer fails when two of its skills share a name, such as a Library skill and a plugin skill: the first one is delivered. A sandbox that runs more than one client keeps no other client's skills where the next client reads them, and a skill's SKILL.md is checked and rewritten each turn, so a tool grant added on the box doesn't last.
