Make Evals account choices easier to read. Accounts show as tinted round avatars, "Runs as" and "Ran as" name the account apart from its server, and one account picker replaces the boxed account tables in Suite settings, the case editor and Set up run. A server with only one account no longer shows a choice in Set up run, the suite header or the case editor. Set up run shows its servers under the title. A completed run reads "Ran as Work on Mail" without the Credentials row or who started it, and Recent runs replace "Ran as" and "Accounts" with one Account column that shows once the runs used more than one account.
