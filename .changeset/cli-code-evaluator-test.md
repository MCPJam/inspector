Adds `mcpjam cloud eval code-evaluator test <file>`, which runs the code evaluator in a local `.sh`, `.py`, `.ts` or `.js` file once against one iteration of a suite's finished run (`--suite`, `--iteration`, and optional `--threshold`, `--id` and `--network`). Nothing is saved; each test boots a paid sandbox.
