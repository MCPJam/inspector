The evaluate run page can propose a description rewrite and read the experiment

**A missing tool is a description problem, not only a matcher one.** Behind `description-experiments-enabled` a failing case can propose a rewrite for a catalog tool, and the run page grows a collapsed card that states the two-arm result in points — or says there are not enough trials — without feeding a verdict. Harness engines stay disabled. Flag off is no request and no DOM.
