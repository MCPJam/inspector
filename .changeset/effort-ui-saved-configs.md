Saved configs can set a reasoning effort. The host Agent tab, the environment composer's model chips (and so the swarm target composer), and the eval and journey judge pickers show the shared effort control beside the model. It is written on the saved model selection, kept on a model change only when the new model lists it (the host tab says so), greyed with the reason on a harness that has not verified an effort, disabled with a tooltip on a bare-id BYOK row where the saved id cannot carry it, and badged "no longer supported" when the catalog stops listing a saved level. A run's judge override still carries the model only; the card shows the suite judge's effort read-only.
