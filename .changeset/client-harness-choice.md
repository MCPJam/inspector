A client with a native harness now shows a Harness section on its card when the backend offers the choice: pick MCPJam Harness or the runtime by its real name (Codex App Server, Claude Agent SDK, Cursor CLI, GitHub Copilot CLI). A pick saves at once and applies to the client's new chats. Only project admins can change it, and a client used by a study another member made needs Team or Enterprise; the disabled section says which applies. Free organizations see their native harness turns left on the native option, a runtime that can't run says why and how to fix it, and Project Environments show the current harness. Project admins can switch the project's native clients to MCPJam Harness from the "Keep using native harnesses" dialog. A client held by another member's study, or keeping a computer your organization can't use, keeps its native harness, and the toast says so. The dialog closes once a client has moved and stays open when none did. In the Playground, a switch made right after the refusal opens a new chat with the refused message in the composer. A client on its vendor's agent loop no longer shows the Computer island or tab, and the run sheet checks its organization keys as it does for other harness clients.
