Organization admins can add a model gateway, such as LiteLLM, from its base URL and key behind the `org-model-gateways` flag. A test fills in the APIs it serves, its models with suggested catalog mappings, and which features and harness clients it works with, run from MCPJam's servers or, for a gateway only your network reaches, from your Inspector.
