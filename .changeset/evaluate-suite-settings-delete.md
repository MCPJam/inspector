Delete a suite from its Suite settings page in Evaluate with the new trash button next to Save settings. It opens the usual delete confirmation, which now warns when unsaved settings changes would be lost, and is disabled while a save is in progress. If the delete fails, unsaved settings stay on the page. Destructive buttons now keep their solid red fill in dark mode instead of a faded one that looked disabled.
