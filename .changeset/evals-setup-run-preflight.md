Setup Run now flags problems before you start: a suite server that isn't connected (with a Connect button), one the project no longer has (blocks Start), and a model provider the organization hasn't enabled (with a link to model settings). Launch failures stay in the sheet instead of a toast, the "Starting run…" toast turns into the outcome instead of a success sitting next to the failure, and local environment suites connect their servers before launching.
