When an organization requires its own provider keys for AI features, the eval run sheet lists every model and judge that can't run on the organization's providers before the run starts, including a judge nobody chose ("Choose a judge model from an organization provider."). A launch the backend refuses shows its whole problem list, in the run sheet and on a swarm's goal list. A feature that can't run on organization keys yet, such as swarms' simulated user, reads as unavailable, with no fix to make. Findings, session insights and swarm analysis that the policy kept from running read "Not analyzed" with the cause (share-link visitors only learn that analysis is unavailable), and Directory readiness says AI observations are unavailable instead of naming credits.
