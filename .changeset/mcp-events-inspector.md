MCP Events (Draft). A new **Events** tab under Inspect shows what event types a server offers and lets you subscribe by poll, push or webhook. It shows a live feed, subscription health and rejected deliveries, and can simulate an event. You can switch between the draft and ChatGPT profiles. A new **Triggers** tab under Explore runs an agent unattended when an event arrives, using your standing instruction and the tools of the chosen environment, with per-trigger rate limits and spending caps and a run history. Event data is always shown and passed to the model as untrusted data.
