Adds the mock server tools: `create_mock_server`, `update_mock_server`, `get_mock_server` (bounded pages: a summary, names by kind, one entry, one field, long strings in chunks, each response inside the 24,000-character text budget), `patch_mock_server`, `refresh_mock_server`, `get_mock_forwarding_policy` and `set_mock_forwarding_policy`. All answer to the `mock-servers-enabled` flag.
