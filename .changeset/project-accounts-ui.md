Behind a flag, a project admin can share an OAuth server's sign-in with the project from its Authorization tab. Admins then connect up to 8 project accounts that every member's hosted runs can act as, members see them read-only, and each member chooses among them in a suite's Accounts settings. Turning sharing off deletes the project accounts. Reconnecting an account that needs it reauthorizes that account in place, and an account with no profile is listed by its name.
