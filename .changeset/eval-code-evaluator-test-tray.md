The code evaluator editor can test the draft on a past iteration from a tray docked above its buttons: pick an iteration, run the test, and see the score, the reason and the logs, without saving anything. An error says it isn't counted as a failure, an iteration with no stored files says the evaluator saw the transcript only, and after an edit the last result stays, marked out of date.
