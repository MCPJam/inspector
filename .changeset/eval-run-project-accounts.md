Choose a project account for each MCP server in an eval run. Case selections take precedence, and run results record the account used by each case.

Quick Run uses the case’s saved account choices and supports one-off selections. Update older Inspectors before running suites that use migrated shared accounts.

Reruns and replays reuse the project accounts recorded for the cases they execute.
