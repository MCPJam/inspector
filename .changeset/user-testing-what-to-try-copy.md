User Testing: the tester's task list is called **What to try** everywhere. The popover used to open on "Optional things to try" above a footnote leading with "Try any, in any order" — telling a tester the list was skippable every time they opened it. The heading now matches the button that opens it, the "Try any, in any order" sentence is gone, and the trigger's accessible name no longer says "optional". The footnote's other half, "This checklist is only for you", stays: it is the one thing about the control a tester cannot work out by looking at it. Nothing about the list's behaviour changed — it still gates nothing and reports no completion back to the creator.
