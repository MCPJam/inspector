`mcpjam readiness submission set` takes `--plugin`, `--plugin-version`, `--clear-plugin`, `--attempt` and `--clear-attempt` for a ChatGPT plugin submission's plugin and attempt. `readiness submission run --plugin-version <id>` names the stored plugin version a ChatGPT plugin submission's run grades, which that run requires.
