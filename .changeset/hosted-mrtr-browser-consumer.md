Wire the BROWSER consumer leg of the hosted MCP 2026-07-28 multi-round-trip (`input_required`) transport (spec §12.5). The hosted server side (durable continuation store, suspend collector, `/api/web/mrtr/*` resume + cancel routes, `data-mrtr-input-required` part, version handshake) already shipped fail-closed; this makes it user-drivable. New exports only.

- **Handshake on the wire.** Hosted chat turns and hosted direct `tools/execute` / `prompts/get` / `resources/read` requests now carry `hostedMrtrVersion: HOSTED_MRTR_VERSION`. The server only registers the suspending collector when it sees this, so a stale bundle is never handed a `continuationId` it can neither render nor resume.
- **A hosted round rail** (`stores/hosted-mrtr-store.ts` + `components/elicitation/HostedMrtrHost.tsx`): the durable-continuation counterpart of the local SSE-backed `MrtrElicitationHost`, reusing the SAME `ElicitationDialog` / `UrlElicitationConsent` (form + modern URL variant) behind the same single-active-dialog election. Rounds dedupe by `continuationId:round`, collect one keyed request at a time, and submit the whole round's `ElicitResult`s together; decline/cancel are responses, not withdrawals.
- **Per-round transport**, because the two hosted surfaces resume differently: a chat round re-drives the turn with an `mrtrResume` descriptor (so the server splices the driven tool result into the suspended tool-call and the agent loop continues), while a direct op resumes over `/api/web/mrtr/resume` — `driveHostedDirectMrtr` runs that loop transparently, so existing call sites still await one result in the verb's own envelope.
- **Terminal outcomes are surfaced, not swallowed:** `completed` / `failed` / `cancelled` / `expired` close the rail, and an `indeterminate` outcome tells the user the call may or may not have run instead of auto-retrying a side effect.
- **Mixed-version rollout fails fast.** An incompatible `version` on a round withdraws the continuation and tells the user to refresh rather than rendering a dialog this bundle could never complete. A user abort — and a resume with no unresolved tool call left in the transcript — likewise withdraws the continuation instead of leaving it to time out.
