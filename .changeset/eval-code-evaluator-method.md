The evaluator library can add code evaluators from a new Code card: give it a name, a file name that picks the language (Python, TypeScript, JavaScript or Bash) and a script, then choose Required or Advisory and a passing score. Suite settings list a suite's code evaluators under Evaluators, where they can be edited or removed. Behind the code evaluators feature flag; with it off, existing code evaluators show read-only and can still be removed. Required is offered only on suites graded at Enforce.
