A Playground Compare pane can run a saved environment instead of a client. Pick one in pane settings, or start Compare from an environment's chat to run it in the first pane. Each environment pane runs its environment's model and servers unless you change them in that pane, and blocks Send while its environment cannot run. A lineup left with one environment pane returns to that environment's chat.
